# AppRedSocialdeViajes
Pruebas Funcionales para una App de Red Social de Viajes | Bootcamp Tripleten (2026)
Descripción: Ejecución de pruebas funcionales en una aplicación de transporte en línea, validando el flujo de usuario, detección de errores y reporte de incidencias para garantizar una experiencia sin errores. • Habilidades destacadas: Pruebas funcionales, UI Testing, informes de errores, documentación de casos de prueba, herramientas como JIRA, DevTools y Figma.
